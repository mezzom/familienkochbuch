# Familienkochbuch

Touchoptimierte Kochansicht: https://mezzom.github.io/familienkochbuch/

`kochbuch.json` enthält Rezepte, Portionsangaben und Tageszuordnung; `app.js` zeigt sie an. Der Wochenplan vom 27.–30. Oktober 2026 wurde aus dem Gesprächskontext datiert. Dienstag und Donnerstag enthalten übernommene vollständige Rezepte. Mittwoch und Freitag wurden am 28.10.2026 anhand der groben Planung neu ausgearbeitet und sind ausdrücklich als ergänzt gekennzeichnet. Die ursprünglichen Grundzutaten bleiben in originalIngredients erhalten; neue Mengen und Zuordnungen sind sichtbar markiert.

Für Updates die Daten ändern, veröffentlichen und die öffentliche Seite prüfen. GitHub Pages veröffentlicht aus `main` im Stammverzeichnis. Persönliche Präferenzen und private Chatdaten gehören nicht in dieses öffentliche Repository.
