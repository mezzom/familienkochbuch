# Familienkochbuch

Touchoptimierte Kochansicht: https://mezzom.github.io/familienkochbuch/

`kochbuch.json` enthält Rezepte, Portionsangaben und Tageszuordnung; `app.js` zeigt sie an. Der Wochenplan vom 27.–30. Oktober 2026 wurde aus dem Gesprächskontext datiert. Dienstag und Donnerstag enthalten übernommene vollständige Rezepte. Mittwoch und Freitag sind als unvollständige Planung gekennzeichnet. Wochen-Einkaufsmengen wurden nicht stillschweigend auf einzelne Gerichte verteilt.

Für Updates die Daten ändern, veröffentlichen und die öffentliche Seite prüfen. GitHub Pages veröffentlicht aus `main` im Stammverzeichnis. Persönliche Präferenzen und private Chatdaten gehören nicht in dieses öffentliche Repository.
